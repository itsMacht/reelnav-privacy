ReelNav Privacy Policy

Effective September 21, 2026

Overview

ReelNav is a browser extension that adds local playback controls and user-requested downloads for visible Instagram media.

Data collection

ReelNav does not collect personal information, browsing history, website content, authentication information, or usage data, and it does not transmit such data to the ReelNav developer. ReelNav does not sell, rent, or share user data. The extension contains no analytics, advertising, tracking, account system, or developer-operated network service.

Local processing

To provide its controls, ReelNav accesses standard HTML media elements on instagram.com and changes local browser media properties such as playback time, volume, mute state, playback speed, fit, and orientation. Story identifiers and media details needed for the visible Story navigator are processed transiently in the current Instagram tab and are not sent to the developer.

ReelNav stores only the user's extension preferences locally through Chrome, including audio mode, volume, speed, skip duration, fit mode, control size, and optional feature toggles. These preferences contain no Instagram URLs, account names, Story identifiers, viewing history, or downloaded media.

When the user clicks Download, ReelNav reads the visible media element's URL and passes that URL and a generated filename to Chrome's Downloads API. Chrome then downloads the media directly from its existing Instagram media host to the user's device. The URL, media, filename, and downloaded file are not sent to or stored by the ReelNav developer.

Permissions and site access

ReelNav runs only on https://www.instagram.com/*. This access is used solely to display and operate the media controls described in the Chrome Web Store listing and to identify the currently visible media after a user clicks Download. The downloads permission is used only to start that requested local download, and the storage permission is used only for the local ReelNav preferences listed above. ReelNav does not search download history, alter unrelated downloads, or access Instagram passwords, private messages, forms, cookies, or account credentials.

Third parties

ReelNav does not send media URLs or files to the developer or to a developer-operated third party. A user-requested download connects directly to Instagram's existing media host. Instagram is a third-party website governed by its own privacy policy. ReelNav is independent and is not affiliated with, authorized by, or endorsed by Instagram or Meta.

Children's privacy

ReelNav does not knowingly collect information from children or from any other user.

Changes to this policy

If ReelNav's data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before those changes are released.
